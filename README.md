# 🧠 Akıllı Metin Analizcisi

Bu proje, metinlerinizi gelişmiş kurallar ve motorlar aracılığıyla analiz eden, sonuçları hem JSON hem de TXT formatında raporlayan Python tabanlı bir akıllı metin analiz aracıdır.

---

## 🚀 Özellikler

* **Otomatik Metin Analizi:** Belirtilen örnek metinler üzerinde hızlı tarama ve veri işleme.
* **Çoklu Raporlama:** Analiz sonuçlarını hem düzenli bir `JSON` formatında hem de okunabilir bir `TXT` raporu olarak dışa aktarma.
* **Modüler Altyapı:** Kolayca genişletilebilir Python betik mimarisi.

---

## 🛠️ Kurulum

Projeyi yerel bilgisayarınıza klonlamak ve çalıştırmak için aşağıdaki adımları takip edebilirsiniz:

1. **Depoyu Klonlayın:**
   ```bash
   git clone [https://github.com/endlessloop88/smart-text-analyzer.git](https://github.com/endlessloop88/smart-text-analyzer.git)
   cd smart-text-analyzer
Sanal Ortamı (venv) Aktif Edin:

Windows için:

Bash
.venv\Scripts\activate
macOS / Linux için:

Bash
source .venv/bin/activate
💻 Kullanım
Analiz motorunu çalıştırmak ve örnek metin üzerinden rapor üretmek için terminale şunu yazabilirsiniz:

Bash
python analgiz_motoru.py
İşlem tamamlandığında analiz_raporu.json ve analiz_raporu.txt dosyaları güncellenecektir.

📁 Proje Yapısı
Plaintext
├── analgiz_motoru.py    # Ana Python analiz motoru
├── analiz_raporu.json   # Yapılandırılmış JSON çıktı dosyası
├── analiz_raporu.txt    # Metin tabanlı analiz raporu
└── ornek_metin.txt      # Test ve analiz için örnek girdi metni
